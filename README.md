# 🏡 Stayvia

### Full-Stack Accommodation Listing Platform

Stayvia is a full-stack web application inspired by accommodation platforms like Airbnb. It allows users to browse, create, edit, and delete property listings.

> 🚧 **Status: Work in Progress**

---

## ✨ Features

* 🏠 Browse accommodation listings
* 🔍 View detailed property information
* ➕ Create new listings
* ✏️ Edit existing listings
* 🗑️ Delete listings
* 🖼️ Display property images
* 💰 Display pricing and location
* 🗄️ MongoDB-powered data storage
* ⚡ Server-side rendering with EJS

---

## 🛠️ Tech Stack

**Frontend:** HTML, CSS, Bootstrap, EJS
**Backend:** Node.js, Express.js
**Database:** MongoDB, Mongoose
**Tools:** Git, GitHub, VS Code

## 🚀 Run Locally

### Clone the repository

```bash
git clone https://github.com/piyushsangwan7/Stayvia.git
cd Stayvia
```

### Install dependencies

```bash
npm install
```

### Start MongoDB

Make sure your local MongoDB server is running.

### Start the application

```bash
nodemon app.js
```

Then open:

```text
http://localhost:7070
```
